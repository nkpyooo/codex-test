# requirements.md

## 1. プロジェクト概要

夫婦で日常情報を共有するiPhone向け生活ダッシュボードアプリ。

## 2. ターゲット

- 夫婦2名利用
- 毎日1〜複数回の軽い利用
- 入力ストレスが少ない体験を重視

## 3. 機能要件

### 3.1 買い物リスト
- 共有チェックリスト
- チェック済みはメイン一覧から非表示
- 過去入力10件程度の履歴保持
- 入力時サジェスト
- ワンタップで追加しやすいUI

### 3.2 見たい映画リスト
- タイトル保存
- 配信先表示（Netflix / Amazon Prime / Disney+）
- 視聴済みステータス
- 配信先の追加しやすい設計

### 3.3 LINE定型文送信
- 1タップでLINE起動＋送信文入力状態へ
- 初期定型文: 「ごはん炊いておいて」
- 将来的に定型文追加を想定

## 4. 非機能要件

- iPhoneネイティブ風
- 白基調・余白多め
- シンプルで可愛い
- 初心者でも保守しやすい実装
- 将来の機能追加を容易に

## 5. MVPの完了条件

- 3機能が単体で動作
- 主要データが端末内保存される
- 1画面ダッシュボードで各機能へアクセス可能
