# ui-guidelines.md

## デザイン原則
- 白ベース
- 高コントラストすぎない配色
- 余白を多く取り、可読性優先
- ワンタップ操作を最短導線に配置

## コンポーネント指針
- カードUI（Widget風）を基本単位にする
- 角丸 14〜20px
- シャドウは弱め
- タイポは iOS標準に寄せる

## レイアウト
- 1画面で概要を俯瞰可能
- 詳細はサブ画面へ遷移
- 下部タブで主要機能へ移動

## 操作性
- 入力欄は大きめ
- サジェストは1タップ適用
- 完了操作はチェック1回で済む

## アクセシビリティ
- 最低44ptタップ領域
- 色だけに依存しない状態表示
- Dynamic Typeを意識した崩れにくい設計
